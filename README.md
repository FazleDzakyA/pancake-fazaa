# 🥞 PANCAKE FAZAA

> *"Flip it. Stack it. Enjoy it."*  
> Browser mini game bertema pancake flipping dengan visual 2D/3D cartoon hangat khas sarapan pagi.

## ✨ Fitur Utama

- 🥞 **6 Fluffy 3D Pancakes**: Tumpukan 6 pancake bervolume tebal khas souffle pancake Jepang / American diner yang montok dan anti-gepeng di semua ukuran layar (Desktop, Tablet, dan Android HP).
- 🥄 **Spatula Physics & Flip Mekanik Nyata**: Spatula perak bergagang kayu yang menyelip di bawah pancake yang dipilih dan membalik sub-stack di atasnya secara fisik.
- 🍁 **Animasi Berhasil Spektakuler**:
  - Tuangan teko sirup maple otomatis (*Maple Syrup Pouring Rig*).
  - Tarian gembira tumpukan pancake (*Stack Celebration Dance*).
  - Hujan konfeti dan kilau bintang warna-warni (*Confetti & Sparkle Shower*).
  - Fanfar melodi kemenangan audio sintetis (*Procedural Web Audio API*).
  - **Berlaku di SEMUA MODE** (Mode Tantangan maupun Mode Santai)!
- 💡 **Petunjuk Pintar Terbatas (1x per Ronde)**: Menggunakan algoritma *Pancake Sort* untuk membantu pemain jika kebingungan. Terkunci setelah 1 kali pakai dan ter-reset setiap kali mengacak tumpukan baru.
- ☕ **2 Mode Permainan**:
  - **Mode Tantangan 🏆**: Selesaikan susunan pancake dari terbesar ke terkecil dengan langkah seminimal mungkin untuk meraih gelar *Master Chef Legendaris*.
  - **Mode Santai ☕**: Bebas membalik sesuka hati, mendengarkan desis panggangan dan menikmati aroma sarapan tanpa tekanan skor.
- 🔊 **Zero-Dependency Sound Engine**: Seluruh efek suara (*flip whoosh*, *sizzle*, *flop landing*, *sparkle*, dan *victory fanfare*) dihasilkan murni secara prosedural menggunakan Web Audio API tanpa file audio eksternal.

## 🎮 Cara Bermain

1. Buka game di browser.
2. Masukkan nama chef kamu (atau langsung klik **LET'S FLIP!**).
3. **Misi:** Susun 6 pancake hingga berurutan dari yang **TERBESAR di bagian bawah (Pancake 6)** sampai yang **TERKECIL di bagian paling atas (Pancake 1)**.
4. Sentuh/klik pancake mana saja untuk menyelipkan spatula dan membalik seluruh tumpukan di atasnya!
5. Gunakan tombol **💡 Petunjuk** jika butuh bantuan (1 kali kesempatan per ronde).
6. Saat tersusun rapi, nikmati tuangan sirup maple keemasan dan selebrasi kemenangan! 🎉

## 🚀 Menjalankan Secara Lokal

Cukup clone repository ini dan buka `index.html` di browser favorit Anda:

```bash
git clone https://github.com/FazleDzakyA/pancake-fazaa.git
cd pancake-fazaa
```

Lalu buka `index.html` langsung di browser atau gunakan server lokal ringan:

```bash
# Menggunakan Python
python -m http.server 8080

# Menggunakan npx serve
npx serve .
```

Kunjungi: `http://localhost:8080`
